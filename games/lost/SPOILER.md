## 一句话

苏念 27 岁，一月查出脑瘤，五月二十一日去世。她怕心脏不好、九月要做手术的妈妈受不了，生前用「回声」（一个本地运行的 AI）学会了自己说话，让它替自己跟妈妈聊天，说自己去大理画壁画了；还设定好在立冬（妈妈最后一次复查之后）17:52 把她写的最后一封信发给妈妈，然后抹掉整台手机。男朋友程屿是照看者，舍不得她「第二次离开」，又没有能取消任务的钥匙，11 月 6 日晚上（认识第一千天）把手机留在了他们认识、也是她海葬的轮渡码头长椅上，让捡到的人替他决定。
最深的一层：妈妈八月十四日编了一只不存在的猫「煤球」试探，回声顺着说记得，妈妈就知道了，但没拆穿，陪女儿把戏演完；11 月 5 日说「妈现在啥都受得住了」是说给女儿听的。

- **林秀芬（妈妈）**：槐镇柳荫街 7 号，小时候在柳湾长大。爸爸 2019 年心脏病走的，妈妈当时听到电话就倒了。九月十日放支架，11 月 5 日最后一次复查。
- **许棠**：大学同学，市二院护士，全程知道；九月替苏念去看了妈妈；立冬早上九点去妈妈家陪着包饺子。

## 推理和想法（story.js 的 QUESTIONS / logic.js 的 RULES）

想法（结论）一层比一层深，结案时只能选已经有的：
- c1 她为了躲程屿去了外地（看到「她说去大理」+「她回程屿很冷」就有）
- c2 她五月就不在了（D3 + D1 或 D2）
- c3 程屿用程序冒充她骗钱（c2 + D4 + 看到妈妈的转账）——这是个陷阱结论
- c4 这一切是她自己安排的（c2 + D5 + D6/D7/D8 里任意两个）
- c5 她们都知道，也都没说破（c4 + D9 + D10）

## 结局（6 个）

结案时先选想法，再选怎么处理：c1 → 失物招领 / 打给妈妈 / 扔进海里；c2 → 交给警察 / 打给妈妈 / 海；c3 → 报警告程屿 / 打给妈妈 / 海；c4、c5 → 等立冬 / 用钥匙取消（要有钥匙）/ 打给妈妈 / 海。
同一个处理在不同想法下正文不一样（`ENDINGS[处理][想法]`，没有就用 `deep`）。「立冬」是真结局：放最后一封信（`LETTER`），然后妈妈的回信（c4、c5 各一封，c5 那封说出了煤球的事），「未送达」。
所有结局最后都是结案报告（没想通的事是黑条）→ 抹掉 → 「你好」。
